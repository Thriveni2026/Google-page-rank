Google PageRank Mini Project

📌 Project Description

Google PageRank is an algorithm used to measure the importance of web pages based on the links between them. A page gets a higher rank when it is linked by other important pages.

This mini project demonstrates how Eigenvalues, Eigenvectors, and Power Iteration are used to calculate the importance of pages in a small network.

🧮 Mathematical Concepts

- Eigenvalue (λ): Represents the scaling factor of an eigenvector.
- Eigenvector: Represents the importance/ranking of each page.
- Power Iteration: An iterative method used to find the dominant eigenvector.

⚙️ How It Works

1. Create a small network of linked web pages.
2. Represent the links using a matrix.
3. Apply the PageRank calculation.
4. Use Power Iteration to update page scores.
5. Continue until the scores become stable.
6. Display the final rank of each page.

🎯 Objective

The objective of this project is to understand how linear algebra is applied in search engines to determine the importance of web pages.

🛠️ Technologies Used

- Python
- Google Colab
- NumPy
- Matplotlib

📊 Example

For a network containing several linked pages, the program calculates a score for each page and ranks them from most important to least important.
